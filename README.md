# swissfans.ch Launch MVP

Startfähige Frontend-MVP-Version mit Landingpage, Login, Registrierung, Creator-Profil und Dashboard-Demo.

## Lokal starten
```bash
npm install
npm run dev
```
Dann öffnen: http://localhost:3000

## URLs
- `/` Landingpage
- `/login` Login
- `/register` Registrierung
- `/creator/alina-zurich` Creator-Profil
- `/dashboard` Creator-Dashboard

## Wichtig
Das ist die Frontend-Basis. Für echte Logins, Uploads und Zahlungen brauchst du Supabase/Clerk, Storage und Payment Provider.
